## 한 줄 요약

- DAS는 서버와 저장장치를 전용 케이블로 직접 연결하는 저장 방식으로, 외장하드를 컴퓨터에 직접 연결하는 구조를 떠올리면 된다.

## 한눈에 보는 구조

| 구분 | 내용 |
|---|---|
| 전체 이름 | Direct Attached Storage |

## PDF 기준 핵심

- DAS는 서버와 저장장치를 전용 케이블로 직접 연결하는 방식이다.
- 일반 가정에서 컴퓨터에 외장하드를 연결하는 것이 여기에 해당된다.

## 개념 설명

### DAS의 의미

- DAS는 네트워크를 거치지 않고 서버에 저장장치가 직접 붙는 구조이다.
- IBM의 SAN 설명 자료는 DAS와 달리 네트워크 기반 저장소는 둘 이상의 컴퓨터가 네트워크를 통해 접근할 수 있다고 설명한다.
- 즉 DAS는 단순하지만 저장 자원을 여러 서버가 유연하게 공유하기 어렵다.

### 특징

- 서버가 저장장치를 직접 관리한다.
- 연결 구조가 단순해 소규모 환경에서 이해하기 쉽다.
- 서버 장애가 저장장치 접근에도 직접 영향을 줄 수 있다.
- 확장성과 공유성이 필요한 환경에서는 SAN이나 NAS가 검토된다.

## 시험 포인트

- DAS는 직접 연결이다.
- 전용 케이블 단서를 기억한다.
- 외장하드 예시를 그대로 기억한다.
- SAN은 별도 전용 네트워크를 구성한다.
- NAS는 파일 공유 중심 네트워크 저장소로 비교될 수 있다.

## 헷갈리는 비교

| 비교 | DAS | SAN |
|---|---|---|
| 연결 | 서버와 저장장치 직접 연결 | 전용 네트워크로 연결 |
| 공유 | 제한적 | 여러 서버 공유에 유리 |
| 예 | 외장하드, 직접 디스크 | 스토리지 네트워크 |

## 예시 또는 암기 포인트

- `Direct`가 보이면 직접 연결을 떠올린다.
- DAS = `서버 옆에 직접 붙은 저장장치`

## 빠른 복습

- DAS는 Direct Attached Storage이다.
- 서버와 저장장치를 전용 케이블로 직접 연결한다.
- 외장하드 연결이 대표 예시이다.
- 구조가 단순하지만 공유와 확장에는 제한이 있다.
