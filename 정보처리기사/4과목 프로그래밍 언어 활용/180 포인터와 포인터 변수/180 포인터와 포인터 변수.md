## 한 줄 요약

- 포인터 변수는 다른 변수의 주소를 저장하는 변수이며, `&`는 주소를 구하고 `*`는 포인터가 가리키는 곳의 값을 참조한다.

```mermaid
flowchart LR
    A["변수 b"] --> B["&b<br/>주소"]
    B --> C["포인터 변수 a"]
    C --> D["*a<br/>가리키는 값"]
```

## 한눈에 보는 구조

| 기호 | 의미 | 예 |
|---|---|---|
| `*` | 포인터 선언 또는 간접 참조 | `int *a;`, `*a` |
| `&` | 변수 주소 구하기 | `a = &b;` |
| 포인터 변수 | 주소를 저장하는 변수 | `int *a` |

## PDF 기준 핵심

- 포인터 변수를 선언할 때는 자료형을 먼저 쓰고 변수명 앞에 간접 연산자 `*`를 붙인다.
- 포인터 변수에 주소를 저장하기 위해 변수 앞에 번지 연산자 `&`를 붙인다.
- 실행문에서 포인터 변수에 간접 연산자 `*`를 붙이면 해당 포인터 변수가 가리키는 곳의 값을 말한다.

## 개념 설명

- cppreference는 포인터가 객체나 함수에 대한 주소를 저장하는 값으로 사용될 수 있음을 설명한다.
- `int *p;`는 `p`가 int형 객체를 가리키는 포인터라는 뜻이다.
- `p = &x;`는 x의 주소를 p에 저장한다.
- `*p`는 p가 가리키는 x의 값을 읽거나 변경한다.

## 시험 포인트

- `*`는 선언에서는 포인터 변수 선언, 실행문에서는 간접 참조로 해석한다.
- `&`는 변수의 주소를 구한다.
- `a = &b;`는 b의 주소를 a에 저장한다.
- `*a`는 a가 가리키는 곳의 값이다.

## 헷갈리는 비교

| 표현 | 의미 |
|---|---|
| `int *a;` | int형 포인터 변수 a 선언 |
| `a = &b;` | b의 주소를 a에 저장 |
| `c = *a;` | a가 가리키는 값이 c에 저장 |

## 예시 또는 암기 포인트

```c
int b = 10;
int *a;
a = &b;
printf("%d", *a);
```

- 출력: `10`
- 암기 문장: `&는 주소, *는 그 주소의 값`

## 빠른 복습

- 포인터 변수는 주소를 저장한다.
- 선언할 때 `*`를 사용한다.
- 주소를 구할 때 `&`를 사용한다.
- 값을 참조할 때 `*`를 사용한다.
