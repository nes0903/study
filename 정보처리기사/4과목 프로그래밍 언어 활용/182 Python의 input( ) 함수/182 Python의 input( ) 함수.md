## PDF 기준 핵심

- `input()` 함수는 키보드로 입력받아 변수에 저장하는 함수이다.
- 입력되는 값은 문자열로 취급되어 저장된다.
- 예: `a = input('입력하세요.')`

## 개념 설명

- Python 공식 문서는 `input()`이 프롬프트를 출력하고 한 줄을 읽은 뒤 문자열로 반환한다고 설명한다.
- 숫자를 입력해도 반환값은 문자열이다.
- 숫자 계산에 사용하려면 `int()`, `float()` 같은 형변환을 해야 한다.

## 시험 포인트

- `input()`은 문자열을 반환한다.
- 프롬프트 문자열을 인수로 줄 수 있다.
- 숫자 계산에는 형변환이 필요하다.
- `int(input())` 형태를 함께 기억한다.

## 헷갈리는 비교

| 표현 | 의미 |
|---|---|
| `a = input()` | 문자열 입력 |
| `a = int(input())` | 입력 문자열을 정수로 변환 |
| `a, b = input().split()` | 공백 기준 문자열 2개 분리 |

## 예시 또는 암기 포인트

```python
a = input("입력하세요.")
```

- 사용자가 `123`을 입력해도 `a`에는 문자열 `"123"`이 저장된다.
- 암기 문장: `input은 일단 문자열`

## 빠른 복습

- `input()`은 키보드 입력 함수이다.
- 입력값은 문자열로 저장된다.
- 숫자 계산에는 형변환이 필요하다.
- 프롬프트를 출력할 수 있다.
